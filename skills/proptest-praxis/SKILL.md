# Agents and property tests: distilling and verifying the model

Every optimized subsystem—an indexed store, an evicting cache, an incremental query planner, a streaming parser, a zero-copy archive, a safe FFI wrapper—is a concrete state machine `C` claiming a Hoare/Lamport **refinement mapping** `alpha: C -> A` (`alpha(step_C(c, op)) == step_A(alpha(c), op)` against a `BTreeMap`, fresh recomputation, or small-step interpreter) or a **forward simulation** relation paired with a representation invariant `RepInv(c)` (such as an evicting cache returning `None` or the latest value while keeping tracked weight equal to live entries). Distill that specification into small executable code and let `proptest` explore thousands of state transitions on the CPU until the diagram commutes or shrinks to a minimal counterexample.

Own the investigation and keep exploring as findings suggest new targets. When delegated a Module Brief inside a `$proptest-campaign` worktree, stay inside that worktree and return findings and cross-module leads to the coordinator.

## 1. Two-stage modeling and directing the search

**Contract-derived oracle, white-box generator (`Oracle from Contract ⊥ Generator from RepInv`):**
1. *Derive the reference model `A` from public docs, call sites, and domain invariants*—using clean standalone types (`BTreeMap`, `Vec`, small interpreters) independent of `C`'s internal helpers—so the oracle expresses the intended contract without sharing `C`'s bugs.
2. *Inspect `C`'s concrete fields, constants, and shortcuts*—noting every field on `C` erased by `alpha(c)`—to define `RepInv(c)` and aim generators directly at `C`'s internal cutoffs: chunk/parallelism thresholds (`16_384` bytes), truncated hash fingerprints (`(h >> 32) as u32`), deferred eviction queues retaining deleted keys, cached strings, and multi-phase registration order. Pin down suspected discrepancies from code reading as executable `RepInv` or `alpha(step_C) != step_A(alpha)` checks.

Keep compile-test-shrink loops in the `1–3s` range: start with self-contained leaf crates, and build narrow standalone test targets or pocket binaries on the discovery branch when a target sits inside a slow-linking binary.

Keep four lenses active throughout the investigation:

- **Myhill–Nerode state distinguishability:** two histories `h1, h2` reaching equal abstract states `alpha(c1) == alpha(c2)` often leave distinct hidden residues in `C`—warmed caches, tombstones, freelist layouts, sharing topologies, unforced lazy fields—waiting for one suffix `w` to separate them. Vary construction histories and observation points over deterministic `Vec<Op>` traces (`loom`/`shuttle` for thread-scheduler interleavings).
- **Small-scope collision density (Jackson's small-scope hypothesis):** omitted interactions never fire, and wide random IDs rarely collide. Pack maximum birthday-paradox collision density into tiny domains before raising case counts.
- **Oracle fidelity:** compare `Ok`/`Err` variant agreement and promised inner values directly; preserve order and counts for sequences, sort while preserving counts for multisets, and deduplicate only for sets.
- **Mutation adequacy and unmasking deeper layers:** calibrate a green suite by snapshotting the target file's bytes, introducing a small invariant break, watching the property catch it, and restoring the saved bytes immediately afterward. Catching a calibration mutant turns a clean run into concrete verification evidence. When a real bug fires, `proptest` stops at the shallowest divergence: committing a validated fix onto the discovery branch and re-running routinely unmasks deeper bugs behind the first assertion.

**Mine existing tests, uncertainty markers, reactive point-fixes, and `Recent Feature × Older Consumer` pairs:**
- Existing strategies often restrict strings to safe regexes (`"[a-z0-9_-]{1,12}"`), omitting quotes (`'`, `"`), backslash runs (`\\`, `\\"`), spaces, leading `-`, `\0`, and delimiters, or call lenient parsers / skip downstream consumers (`to_args() -> clap::try_parse_from()`).
- Grep for maintainer uncertainty markers (`TODO`, `FIXME`, `HACK`, `workaround`, `subtle`, `careful`) pointing to delicate invariants.
- Check `git log` for **recent reactive point-fixes** (*"How Do Fixes Become Bugs?"*—hotfixes, release-blocker patches, security fixes, crash band-aids): hurried single-input patches often update one half of a coupled invariant (e.g., changing growth from `*= 2` to `+ 128` while an adjacent reset still assumes `*= 2`), regress `--release` or cleanup paths, or guard one call site while sibling methods share the same gap. Reconstruct the general `RepInv(c)` the commit aimed to restore and test the whole module against it, alongside **recently added features/modes** meeting **older caches, visitors, serializers, and GC passes**.

**Adaptive search allocation — breadth vs. depth:** get simple models running early and keep productive suites executing while building others, allocating effort across new modules, stronger laws, and sharper generators by expected information gain per compile/run second.

## 2. Core algebraic laws and reference-model patterns

Pick the strongest applicable rung on **Hughes's specification ladder** (`Refinement Mapping -> In-Repo McKeeman Differential -> Commuting Paths ("two ways to reach the same state") -> EMI / Metamorphic Rewrite -> Planted-Solution / Blum Checker -> RepInv Conservation`) so every suite tests a substantive law rather than `is_ok()` smoke checks:

- **In-repo differentials, Blum result checkers, and `EMI`:** check whether the repo already contains a second path for the same contract (**McKeeman differential**: `SIMD vs. scalar fallback`, `incremental vs. cold batch`, `streaming vs. whole-slice`, `JIT vs. interpreter`, `Borrowed/Archived vs. Owned`). When outputs are non-unique or expensive to compute, verify certificates in linear time (**Blum checkers**: path validity, topological order + multiset conservation) or apply **equivalence-modulo-inputs (`EMI`) / metamorphic** rewrites (`e ~ e' => eval(e) == eval(e')`: reordering independent clauses, pruning dead branches, splitting chunks).
- **Coupled representations — refinement mappings & `RepInv(c)`:** step coupled structures (map + eviction queue, primary + secondary index, overlay + backing store, LRU + pool) alongside a `BTreeMap`/`Vec`/set model (or cache simulation relation) across overwrites, removals, reinsertions, capacity cliffs, and empty/singleton states, checking `RepInv` (weight sums, index bijections) at every step.
- **Caches and incremental state — recomputation naturality:** assert `cached_query(c) == recompute_from_scratch(alpha(c))` across warmups, size-preserving edits, mode switches, and transitive invalidations.
- **Graphs, query planners, and AST rewrites — semantic preservation:** compare optimized traversals and rewritten plans against a tiny interpreter or small-instance enumeration across cycles, diamonds, shared DAG subgraphs, disconnected roots, and deletion holes.
- **Scoping and visibility filters — relational models:** compare fast routing, tenant, or field-visibility passes against an explicit `(actor, item, rule) -> bool` filter over a flat collection.
- **Fallible transitions, external `IO` effects, and `Future` cancellation (`StateT S (Except E)` vs. `ExceptT E (State S)`):** check whether `Err` rolls state back or leaves mutated state and **external filesystem, cache, or symbol-table side effects** behind (such as staging a cache file before validation fails). Schedule deterministic `Err` returns on step `k` (testing partial-init `Drop`), and drop manually polled `Future`s at arbitrary `Poll::Pending` points before reusing shared state.
- **Layered configs and non-commutative precedence monoids:** check associativity, `None` vs. `Some(empty)` identity, and `first-wins` vs. `last-wins` precedence across CLI flags, env vars, defaults, and multi-step request/session merges (including options carried over from a failed or retried step).
- **Re-entrant callbacks:** supply trait/callback implementations (`Ord::cmp`, `Hash`, `Iterator`, `Drop`, `serde` visitors) that query or mutate `C` while `RepInv(c)` is temporarily open mid-operation.
- **Parsers, two-pass scanners, and Rely–Guarantee `produce -> consume` pipelines:** verify `parse(print(x)) == Ok(x)`, composed `produce -> consume` preconditions and input-output relations across module boundaries (pushing past intermediate `String` formatting), and streaming chunk homomorphism (`parse_chunks([a, b]) == parse_chunks([a ++ b])`). Where two passes scan the same input (boundary splitter then parser, or right-to-left vs. left-to-right), check quote/escape parity (`\\"`). Where builders interpolate strings into AST leaves (URLs, globs, filters, queries, CLI args), check **AST spine invariance**: varying leaf characters must either return `Err` or change leaf values alone in `parse(render(ast))`, keeping outer AST constructors and authorities fixed.
- **Budgets, numeric/IEEE-754 cliffs, and Galois span pushforwards:** verify byte/depth/step trackers across multi-chunk and `Err` paths; test `0`, `1`, `cap ± 1`, `T ± 1`, integer extrema, `2^53` float integers, `-0.0`/`+0.0` in `Eq`/`Hash`, `NaN` ordering, stateful Kahan retry compensation, and byte-span remapping across length-changing UTF-8/normalization/escaping transforms.
- **Quotient congruence (`x ~ y => obs(x) == obs(y)`), `plan` vs. `apply`, and projection symmetry:** verify `a == b => hash(a) == hash(b)`, `cmp(a, b) == Equal`, idempotence `norm(norm(x)) == norm(x)`, and agreement on observations promised to ignore representation (`0!` epochs, `.0` suffixes, `Archived<T>` vs. owned `T`); compare dry-run / `list_entries` / size-estimation passes against actual execution (`M_scan == M_apply`), and check validators vs. evaluators that read different projections (map keys vs. values, first vs. last duplicate key, empty-body defaults `"" -> "{}"`).

## 3. Build high-density generators and shrinking-friendly ASTs

- **Operation-sequence ASTs & minimal alphabets:** represent histories as an explicit `Op` enum paired with tiny structural parameters (`cap` `0..7`, chunk sizes `1..5`, `T - 2..=T + 2`). Build string/path/URI/glob/CLI inputs combinatorially from `"a"`, `"b"` crossed with the grammar's own delimiters (`'/'`, `':'`, `' '`, `'\\'`, `'"'`, `'*'`, `'-'`, `'.'`, `'\0'`, multibyte UTF-8) over lengths `0..8` so counterexamples shrink immediately to 2–5 character literals (`"/@a:a"`, `"\\[*]"`).
- **Planted solutions (`inverse`), equivalence pairs (`related_pair`), and decoupled inhabitants:** for constraint or resolution domains, generate a valid witness *first* and build the problem instance around it to test feasibility via a Blum checker (applying objective bounds only where optimality is promised, and exact equality only where solutions are unique). Generate `x ~ y` pairs via equivalence-preserving rewrites, and vary normally covarying safe parameters (`bytes: b"a"` vs. `declared_count: 2`) independently across all safe inhabitants.
- **Small pools, Groce swarm subsets, and `sample::Index` shrinking:** use `0..4` key pools with distinct replacement values, embed motifs (`warm -> mutate -> read`, `remove -> reinsert`, `populate -> clear -> repopulate`, `snapshot -> mutate -> read_both`), and mix **Groce swarm-subset traces** (`3–5` `Op` variants per trace so `Clear` and eager `Get` don't suppress `Resize` or cold `Snapshot`s) with full-vocabulary traces. Prefer `proptest::sample::Index` over `prop_assume!` or deep `prop_flat_map` chains (and key custom procedural PRNG draws by `(label, occurrence)` shrinking containers before leaves). Uphold documented API/`unsafe` preconditions while varying everything current callers merely happen to keep constant.

## 4. Run hermetically on CPU and sanitizers

Run exploration in compiled CPU code (`proptest`, `hypothesis`, `fast-check`, `rapidcheck`) in disposable clones or `git worktree` checkouts, capping `CARGO_BUILD_JOBS`, formatting `prop_assert_eq!` failures as equation diffs (`step {k} ({op:?}): alpha(impl) = {actual:?}, model = {expected:?}`), and redirecting verbose output to unversioned log files.

**Hermetic fixtures, OS write confinement, and Reynolds frame laws (`modifies(work) * UNCHANGED(outside)`):** give path, archive, symlink, config, and cleanup tests a per-case `TempDir`, spawning a child `Command` (`.current_dir(&work_dir).env(...)`) per case when code reads `$HOME`, `$TMPDIR`, or `cwd` from process globals (since `cargo nextest` isolates `#[test]` functions rather than shrink steps). When generated paths (`"/"`, `".."`, symlinks) reach mutating filesystem calls, wrap the runner in **OS write confinement** (`bwrap --ro-bind / / --bind "$temp" "$temp"`, namespaces/Landlock, `sandbox-exec`, or a container) and nest `temp/d1/d2/work/` with writable ancestor sentinels (`temp/a`, `temp/d1/a`, `temp/d1/d2/a`) inside the snapshotted tree so even error-swallowing cleanup code (`let _ = fs::remove_file(...)`) hits an observable sentinel caught by `snapshot_tree(temp, excluding = "d1/d2/work") == UNCHANGED`.

**Safe-wrapper soundness and `--release` parity:** test pure-Rust `unsafe`, arenas, and `Pin` under `Miri` (`PROPTEST_DISABLE_FAILURE_PERSISTENCE=1 PROPTEST_CASES=16 cargo +nightly miri test`), and C/FFI wrappers under `ASan`/`UBSan` at minimal `0–2` byte sizes, using that command directly as the regression gate and checking `--release` (`-DNDEBUG`) alongside debug builds.

## 5. Diagnose, verify with fresh eyes, and extract fixes

When a run surfaces a failing seed or sanitizer backtrace, read it directly as a state-transition equation: locate the first diverging step `k`, inspect `step_C` alongside `step_A` and `RepInv(c)`, isolate minimal conditions via **delta-debugging (`ddmin`)**, sweep sibling methods (`rg`), and group traces resolved by restoring one invariant into a single **root-cause equivalence class**.

Write a clean, minimal standalone `#[test]` from scratch at the established contract boundary (without discovery-branch scaffolding) and review it in a fresh context against the target commit's docs, explicit preconditions, and `--release` / sanitizer behavior—confirming a settled bug fails before the fix and passes after it across the generalized property suite, or capturing a passing characterization test alongside competing options when the specification itself is silent. State accurately whether outer callers exercise the path or remain unverified.

Match packaging to ownership: cut minimal surgical fix branches for external repositories, apply [`root-and-branch`](../root-and-branch/SKILL.md) when a workspace sweep in an owned codebase reveals a shared representation gap across multiple sites, and use [`write-reports`](../write-reports/SKILL.md) (or the repository's `CONTRIBUTING.md` / `SECURITY.md` channel) for design tradeoffs and maintainer reports. Merge validated fixes onto the discovery branch to unmask deeper layers and continue exploring.

Use [`references/methods.md`](references/methods.md) when grounding or extending these specification, generator, and verification methods.
