# Agents and property tests: refinement mappings and algebraic laws

Every optimized subsystem—an indexed store, an evicting cache, an incremental query planner, a streaming parser, a compact archive, a low-level systems module—is a concrete state machine `C` claiming a Hoare/Lamport **refinement mapping** `alpha: C -> A` (`alpha(step_C(c, op)) == step_A(alpha(c), op)` against an ordinary finite map, naive recomputation, or small-step interpreter) or a **forward simulation** relation paired with a representation invariant `RepInv(c)`. Distill that specification into small executable code and explore thousands of randomized state transitions on the CPU until the diagram commutes or shrinks to a minimal counterexample.

Select and combine the generative lenses below as the module's structure warrants, and load **only the single harness reference matching the target environment** before writing test code: [`references/rust.md`](references/rust.md), [`references/python.md`](references/python.md), [`references/go.md`](references/go.md), or [`references/rust-driver.md`](references/rust-driver.md) (for other languages, C/C++, CLI/daemon targets, or environments without an installed property-testing library). Own the module's specification and test suite end to end: when running standalone, carry confirmed divergences through to clean fix branches; when given a scoped module brief in an assigned worktree, complete that module's verification certificate—covered laws, verified invariants, minimal native unit tests, candidate repairs, and any open interface assumptions—right inside that worktree as a self-contained result.

## 1. Modeling and search direction

**Uninterpreted sorts; two-phase oracle firewall (`Black-Box step_A ⊥ White-Box ker(alpha)`).** De-semanticize domain nouns immediately when constructing `A`: project domain-heavy entities (principals, routes, headers, archive entries, frames, queries) onto **uninterpreted finite sorts** (`Atom(0..3)`, `Key(0..3)`, `Scope(0..2)`, `Seg`, `Edge`) and pure set-theoretic relations (`R subseteq Atom x Scope`) so reassuring variable names never mask broken logic. Derive `alpha(c)`, `RepInv(c)`, and `step_A` from **public signatures, docs, and caller contracts first** in the simplest brute-force complexity class (`O(N^2)` scan, exact unbounded/rational arithmetic, naive full rebuild—before reading `C`'s method bodies so fast-path bugs cannot leak into a tautological mirror oracle). *Then* inspect `C`'s fields, constants, and fast-path branches—noting every concrete detail erased by `alpha(c)` (`ker(alpha)`)—to aim generators at internal cutoffs: chunk/parallelism thresholds (`16_384` bytes), truncated hash fingerprints, deferred eviction queues retaining deleted keys, cached derived strings, and multi-phase registration order. Keep edit-run-shrink loops in the `0.5–3s` range by targeting leaf packages or narrow pocket binaries.

**Myhill–Nerode distinguishability; mutation adequacy; unmasking layers.** Two histories `h1, h2` reaching equal abstract states `alpha(c1) == alpha(c2)` often leave distinct hidden residues in `C`—warmed caches, tombstones, freelist layouts, sharing topologies, unforced lazy fields, or thread-interleaving states—waiting for one distinguishing suffix `w` to separate them. Compare success/error agreement and promised inner values directly: preserve order and counts for sequences, sort while preserving counts for multisets, and deduplicate strictly for sets. Calibrate an all-green suite via **mutation adequacy**: snapshot the target file's bytes, introduce a small invariant break, confirm the property catches it, and restore the saved bytes immediately. When a real failure fires, committing a validated fix onto the discovery branch and re-running routinely unmasks deeper divergences behind the first assertion.

**Existing-suite gaps; uncertainty markers; code-only commit hunks.** Existing tests frequently restrict strings to narrow regexes (`"[a-z0-9_-]{1,12}"`—omitting quotes, `\\` / `\\"` runs, whitespace, empty strings, Unicode boundaries, and grammar delimiters) or stop at an intermediate string instead of checking the downstream consumer (`format_record() -> parse_record()`). Grep for maintainer uncertainty markers (`TODO`, `FIXME`, `HACK`, `workaround`, `subtle`). Because commit messages in many repositories are very long (PR templates, changelogs, review threads) and bloat the context window toward premature compaction, inspect recent history strictly via commit hashes, file stats, and code diffs (`git log -n 20 --format="%h" --stat -- <path>` and `git show --format="" <sha> -- <path>`) to spot **reactive single-input point-fixes** (*"How Do Fixes Become Bugs?"*—narrow guards that update one half of a coupled invariant, such as changing growth from `*= 2` to `+ 128` while an adjacent reset still assumes `*= 2`, or check one call site while sibling methods share the same assumption) alongside **recently added features/modes** meeting older caches, visitors, serializers, and GC passes.

## 2. Algebraic laws and defect calculus

**Specification ladders; McKeeman differentials; Blum checkers and `EMI`.** Choose the strongest applicable rung on **Hughes's specification ladder** (`Refinement Mapping -> In-Repo McKeeman Differential -> Commuting Paths ("two ways to reach the same state") -> EMI / Metamorphic Rewrite -> Planted-Solution / Blum Checker -> RepInv Conservation`) rather than trivial non-error smoke checks. Check whether the repo already holds a **McKeeman differential** pair (`SIMD vs. scalar fallback`, `incremental vs. cold batch`, `streaming vs. whole-slice`, `JIT vs. interpreter`, `zero-copy view vs. owned value`). Where outputs are non-unique or expensive to compute, verify certificates in linear time (**Blum result checkers**: path validity, topological order + multiset conservation) or apply **equivalence-modulo-inputs (`EMI`) / metamorphic** rewrites (`e ~ e' => eval(e) == eval(e')`: reordering independent clauses, pruning dead branches, splitting chunks).

**Coupled carriers; referential integrity (`dom(idx) == live(alpha(c))`); recomputation naturality.** Step coupled representations (map + eviction queue, primary + secondary index, generational arena + handles, buffer + explicit `len_tag`, overlay + backing store) alongside `A` across overwrites, removals, reinsertions, capacity cliffs, and empty/singleton states, checking `RepInv(c)` (`dom(idx) == live(alpha(c))`, `len_tag == slice.len()`) at every step. Assert `cached_query(c) == recompute_from_scratch(alpha(c))` across warmups, size-preserving edits, mode switches, and transitive invalidations; compare optimized graph/planner/AST passes against small interpreters over cycles, diamonds, shared DAGs, and deletion holes; and check scoping or visibility filters against flat `(actor, item, rule) -> bool` comprehensions.

**Monad-transformer ordering; re-entrant invariants; non-commutative monoids.** Distinguish atomic rollback (`StateT S (Except E): S -> Result<(A, S), E>`) from mutated error state (`ExceptT E (State S): S -> (Result<A, E>, S)`) where a rejected step leaves `c' != c`, `¬RepInv(c')`, or uncommitted cache/filesystem entries behind. Schedule deterministic error returns on step `k` (exercising partial-init cleanup and destructors), cancel async tasks or iterators mid-suspension, supply re-entrant callbacks/comparators/visitors that query or mutate `C` while `RepInv(c)` is open, and test layered config/option merges for associativity, absent vs. empty identity, and `first-wins` vs. `last-wins` precedence across retried or rejected steps.

**Section–retractions; Rely–Guarantee composition (`Im(f) subseteq Pre(g)`); unquote spine invariance.** Verify `parse(print(x)) == x`, monoidal chunk homomorphism (`parse_chunks([a, b]) == parse_chunks([a ++ b])`), and multi-stage **Rely–Guarantee** composition `g(f(x))` over `x in Pre(f)`—directly probing the unowned middle `Im(f) \ Pre(g)` where unit suites of `f` and `g` alone each assume the other canonicalizes or rejects an input. Where builders substitute strings into structured AST leaves (URIs, globs, filters, queries, CLI argv, configs), verify **unquote / AST spine invariance** (`parse(render(Tree(leaf)))`): varying leaf characters must either return an error or modify data leaves alone on re-parse, never promoting leaf characters into outer AST constructors, operator arities, or structural fields.

**Non-commuting projections (`pi_check != pi_eval`); quotient congruence; `Z_2^w` and IEEE-754 rings.** Whenever two stages inspect one input—`dry_run` / `list_entries` / size pre-scan vs. execution (`M_scan == M_apply`), validator vs. evaluator, pre-splitter vs. slice parser, `left-to-right` vs. `right-to-left` quote and backslash parity (`\\"`), duplicate-key `first` vs. `last` projection, or empty-body defaults (`"" -> "{}"`)—assert they factor through the same canonical value (`pi_check(x) == pi_eval(x)`). Verify quotient congruence (`a == b => hash(a) == hash(b)`, `cmp(a, b) == Equal`, `norm(norm(x)) == norm(x)`, and `obs(a) == obs(b)` across `0!` epochs, `.0` suffixes, and zero-copy vs. owned forms), check fixed-width modular arithmetic (`Z_2^w` wraparound or signed truncation) against exact mathematical integers `Z` in `alpha(c)`, and probe IEEE-754 cliffs (`2^53`, `-0.0`/`+0.0`, `NaN`, stateful Kahan retry compensation) and UTF-8 byte-span pushforwards.

## 3. High-density generators and shrinking

**Small-scope hypothesis; free-monoid alphabets; planted and decoupled inhabitants.** Apply **Jackson's small-scope hypothesis**: pair explicit `Op` variants with tiny capacities (`0..7`), chunk sizes (`1..5`), `0..4` key pools, and threshold neighborhoods (`T - 2..=T + 2`), building string/path/URI/glob/CLI inputs combinatorially from `"a"`, `"b"` crossed with the grammar's own delimiters over lengths `0..8` so counterexamples shrink to 2–5 character literals (`"a:b"`, `"\\[*]"`). For constraint or resolution domains, plant a valid witness *first* and construct the problem around it to test feasibility via a Blum checker (applying objective bounds only where optimality is promised, and exact equality only where solutions are unique). Generate `x ~ y` pairs via equivalence-preserving rewrites, and vary normally covarying valid parameters (`bytes: b"a"` vs. `declared_count: 2`) independently across all legal inhabitants.

**Groce swarm subsets; index-preserving shrinking; caller-habit independence.** Embed history motifs (`warm -> mutate -> read`, `remove -> reinsert`, `populate -> clear -> repopulate`, `snapshot -> mutate -> read_both`) and mix **Groce swarm-subset traces** (`3–5` `Op` variants and feature flags per trace so `Clear` and eager `Get` do not suppress `Resize` or cold `Snapshot`s) with full-vocabulary traces. Select existing keys and handles by integer index modulo live collection length rather than rejection filtering so deleting an early step preserves target validity during shrinking, order compound types so outer operation lists shrink before inner leaves, and vary everything permitted by documented API preconditions regardless of current caller habits.

## 4. Referential transparency, effect reification, and fix extraction

**Referential transparency; reified `FsMap` handlers; ambient-variable elimination.** Property execution and shrinking assume every trial is a **referentially transparent** pure function `prop(input)` whose result is independent of trial count, execution order, and parallel test workers. Whenever `C` performs filesystem, archive, symlink, environment, or subprocess I/O, reify the effect handler into a pure state transition `FsMap -> (Result, FsMap)` over a fresh per-trial temporary directory created *inside* the trial closure: materialize the initial finite map `(RelPath -> Entry)` under a nested working prefix (`root/d0/d1/work` alongside sibling entries `root/a`, `root/d0/a` deeper than generated `".."` steps so parent-relative paths remain closed, total transitions compared directly via `snapshot_tree(root) == model_tree`), eliminate ambient free variables (`$HOME`, `$TMPDIR`, `cwd`) via clean-environment child processes with explicit working directories, and evaluate absolute `"/"` or mount-level paths inside an ephemeral container rootfs so the entire filesystem codomain stays a finite, reproducible value.

**Abstract-machine definedness; `Im(p) \ Pre(g)` triage; clean-boundary completion.** Name tests, variables (`sut`, `model`, `ops`, `expected`), and assertion diagnostics directly after the law (`parse_render_preserves_ast_spine`, `step {k} ({op}): alpha(sut) = {actual}, model = {expected}`), keeping fixtures in minimal `"a"`/`"b"`/`0..4` inhabitants. Check abstract-machine definedness (`step_C != ⊥`: aliasing/provenance, slice bounds `idx < len`, lifetime validity `live(id) in dom(alpha)`, data-race freedom, and `Z_2^w` / elided-assert parity in optimized release builds), redirecting verbose runner stderr to log files and extracting only the compact `(file:line, seed, violated_side_condition)` tuple rather than echoing raw tool banners. Verify `x in Pre(f)` under release builds: when an internal helper `g` fails at `x !in Pre(g)`, lift one step upstream (`g(p(raw))` for `raw in Pre(p)`) and record `Im(p) subseteq Pre(g)` as a verified inductive invariant when uninhabited. For genuine contract violations, apply **delta-debugging (`ddmin`)**, sweep sibling methods (`rg`), quotient traces sharing one broken invariant into a single **root-cause equivalence class**, and write a clean, dependency-free native unit test from scratch at the established contract boundary—confirming pre-fix failure and post-fix pass (cutting minimal surgical patches externally or tightening types so `|Type| == |ValidStates|` in owned code), or recording a passing characterization test when docs are silent, while stating accurately whether outer callers are cited or `unverified`. That verified native test, repair or option note, verified invariants, and open interface assumptions complete the module's verification certificate.
