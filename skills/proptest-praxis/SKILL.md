# Agents and property tests: refinement mappings and algebraic laws

Every optimized subsystem—an indexed store, an evicting cache, an incremental query planner, a streaming parser, a compact archive, a low-level systems module—is a concrete state machine `C` claiming a Hoare/Lamport **refinement mapping** `alpha: C -> A` (`alpha(step_C(c, op)) == step_A(alpha(c), op)` against an ordinary finite map, naive recomputation, or small-step interpreter) or a **forward simulation** relation paired with a representation invariant `RepInv(c)`. Distill that specification into small executable code and explore thousands of state transitions on the CPU until the diagram commutes or reduces to a minimal counterexample.

Select and combine the generative lenses below as the module warrants, and load **only the single harness reference matching the target environment** before writing test code: [`references/rust.md`](references/rust.md), [`references/python.md`](references/python.md), [`references/go.md`](references/go.md), or [`references/rust-driver.md`](references/rust-driver.md) (for other languages, C/C++, CLI/daemon targets, or checkouts without an installed property-testing library). Own the module's specification and test suite end to end: when running standalone, carry confirmed discrepancies through to clean bugfix branches; when given a scoped worker brief with explicit output paths, write atomic failing-case notes, candidate patches, verified invariants, and open cross-module or setup requests directly to the assigned files and return a concise one-line receipt.

## 1. Modeling and search direction

**Uninterpreted sorts; carrier fidelity; two-phase model construction (`black-box step_A`, then `white-box cutoffs`).** De-semanticize domain nouns immediately when constructing `A`: project domain entities (records, routes, headers, archive entries, frames, queries) onto **uninterpreted finite sorts** (`Atom(0..3)`, `Key(0..3)`, `Scope(0..2)`, `Seg`, `Edge`) and pure relations (`R subseteq Atom x Scope`) so reassuring identifiers never mask broken logic. Keep `A`'s carrier at least as expressive as `C`'s valid inputs—for example, represent multimaps, headers, or duplicate-key objects as ordered `Vec<(Key, Val)>` pairs rather than collapsing duplicates into a deduplicating `Map`/`dict` before `C` defines their precedence. Derive `alpha(c)`, `RepInv(c)`, and `step_A` from **public signatures, docs, and caller contracts first** in the simplest brute-force complexity class (`O(N^2)` scan, exact unbounded/rational arithmetic, naive full rebuild—before reading `C`'s method bodies so fast-path bugs cannot leak into a mirror oracle). *Then* inspect `C`'s fields, constants, and branches to aim generators at internal cutoffs: chunk thresholds (`16_384` bytes), truncated hash fingerprints, deferred eviction queues, cached strings, and registration order. Keep edit-run loops in the `0.5–3s` range via leaf packages or pocket binaries.

**Myhill–Nerode distinguishability; mutation adequacy; unmasking to zero.** Two histories `h1, h2` reaching equal abstract states `alpha(c1) == alpha(c2)` often leave distinct concrete residues in `C`—warmed caches, tombstones, freelist layouts, sharing topologies, lazy fields, or thread-interleaving states—waiting for one suffix `w` to separate them. Compare success/error agreement and inner values directly (preserving order and counts for sequences, sorting with multiplicity for multisets, deduplicating for sets). When running standalone (or before closing an all-green module), verify **mutation adequacy** by making a small temporary logic flip, confirming a property fails, and restoring the file immediately. When a real failure fires, apply a candidate fix in the discovery workspace and re-run iteratively **until mismatches reach `0`** (or hit a genuine specification question), recording each newly unmasked root cause separately while the harness is warm.

**Existing-suite gaps; uncertainty markers; mode interactions.** Existing tests often restrict strings to narrow regexes (`"[a-z0-9_-]{1,12}"`—omitting quotes, `\\` / `\\"` runs, whitespace, empty strings, Unicode boundaries, and grammar delimiters) or stop before downstream consumers (`format_record() -> parse_record()`). Grep for uncertainty markers (`TODO`, `FIXME`, `HACK`, `workaround`, `subtle`) and target **cross-stratum mode interactions** where retrofitted capabilities—streaming, async cancellation, case-folding, zero-copy views, or incremental caching—cross older core data structures, visitors, and serializers without forwarding flags or updating coupled state.

## 2. Algebraic laws and defect calculus

**Specification ladders; McKeeman differentials; Blum checkers and `EMI`.** Prefer the strongest applicable rung on **Hughes's specification ladder** (`Refinement Mapping -> In-Repo McKeeman Differential -> Commuting Paths -> EMI / Metamorphic Rewrite -> Planted-Solution / Blum Checker -> RepInv Conservation`) over non-error smoke checks. Use existing **McKeeman differential** pairs (`SIMD vs. scalar`, `incremental vs. cold batch`, `streaming vs. whole-slice`, `JIT vs. interpreter`, `zero-copy view vs. owned`). Where outputs are non-unique or costly to compute, verify certificates in linear time (**Blum result checkers**: path validity, topological order + multiset conservation) or apply **`EMI` / metamorphic** rewrites (`e ~ e' => eval(e) == eval(e')`).

**Coupled carriers; referential integrity (`dom(idx) == live(alpha(c))`); cache-recomputation equivalence.** Step coupled representations (map + eviction queue, primary + secondary index, arena + handles, buffer + explicit `len_tag`, overlay + backing store) alongside `A` across overwrites, removals, reinsertions, capacity cliffs, and empty/singleton states, checking `RepInv(c)` (`dom(idx) == live(alpha(c))`, `len_tag == slice.len()`) after every step. Assert `cached_query(c) == recompute(alpha(c))` across warmups, size-preserving edits, mode switches, and transitive invalidations; check graph/planner/AST passes over cycles, diamonds, shared DAGs, and deletion holes; and verify query filters and predicate pushdowns against flat brute-force comprehensions (`iter().filter(pred)`).

**Error-rollback atomicity (`StateT` vs. `ExceptT`); non-destructive value semantics; non-commutative merges.** Distinguish atomic rollback (`StateT S (Except E)`) from mutated error state (`ExceptT E (State S)`) where rejected steps, mid-suspension async cancellations, or re-entrant callbacks/visitors leave `c' != c`, `¬RepInv(c')`, or leftover entries. Verify **non-destructive value semantics (`const` / reuse equivalence)**: read-only queries, serializers, comparators, and diff/patch builders should leave input values reusable by the caller (`let p = generate(a, b); apply(a, p)` matching `apply(fresh_a, p)`), and multi-argument operations should honor documented self- or shared-argument contracts (`dst == src` or shared subtrees). Test layered config/option merges for associativity, absent vs. empty identity, and `first-wins` vs. `last-wins` precedence.

**Roundtrip and chunk homomorphisms; Rely–Guarantee composition (`Im(f) subseteq Pre(g)`); AST spine invariance.** Verify `parse(print(x)) == x`, chunk homomorphism (`parse_chunks([a, b]) == parse_chunks([a ++ b])`), and multi-stage **Rely–Guarantee** composition `g(f(x))` over `x in Pre(f)`—probing the unowned middle `Im(f) \ Pre(g)` where unit suites of `f` and `g` each assume the other normalizes or rejects an edge case. Where builders substitute strings into structured AST leaves (URIs, globs, filters, queries, CLI argv, configs), verify **structural AST spine invariance** (`parse(render(Tree(leaf)))`): varying leaf characters must either error or change data leaves alone on re-parse, leaving outer AST constructors, operator arities, and structural fields invariant.

**Two-stage agreement (`pi_check(x) == pi_eval(x)`); quotient congruence; `Z_2^w` and IEEE-754 arithmetic.** Whenever two stages inspect one input—`dry_run` / pre-scan vs. execution (`M_scan == M_apply`), validator vs. evaluator, pre-splitter vs. slice parser, `L->R` vs. `R->L` quote/backslash parity (`\\"`), duplicate-key `first` vs. `last` lookup, or empty defaults (`"" -> "{}"`)—assert `pi_check(x) == pi_eval(x)`. Verify congruence (`a == b => hash(a) == hash(b)`, `cmp(a, b) == Equal`, `norm(norm(x)) == norm(x)` across leading zeroes, `.0` suffixes, case-folded keys, and zero-copy views), compare fixed-width `Z_2^w` arithmetic against exact `Z` in `alpha(c)`, and probe IEEE-754 cliffs (`2^53`, `-0.0`/`+0.0`, `NaN`, Kahan retry state) and UTF-8 span pushforwards.

## 3. Two-tier search: bounded exhaustion and swarm shrinking

**Shortlex `SmallCheck` exhaustion; free-monoid alphabets; planted and decoupled inhabitants.** Pair **Jackson's small-scope hypothesis** (`0..7` capacities, `1..5` chunks, `0..4` keys, `T - 2..=T + 2` cutoffs, strings built from `"a"`, `"b"` crossed with the grammar's own delimiters) with **two-tier search**:
1. *Shortlex bounded exhaustion (`SmallCheck`):* over tiny alphabets and depths (`lengths 0..=3`, `200–2,000` cases running in `< 0.1s`), enumerate inputs exhaustively in increasing size order so small-scope coverage is `100%` complete and the very first failure (`"\\\""`, `{"a":0,"a":1}`) is already smallest under the chosen enumeration.
2. *Randomized **Groce swarm-subset** traces (`5..50` steps):* sample `3–5` `Op` variants and feature flags per trace alongside full-vocabulary traces (`warm -> mutate -> read`, `remove -> reinsert`, `snapshot -> mutate -> read_both`) so `Clear` or eager `Get` cannot suppress deep capacity/tombstone states.

Plant valid feasible instances first for constraint domains (checking feasibility via a Blum checker, objective bounds only where optimality is promised, and equality only under uniqueness). Select live keys/handles by integer index modulo live length rather than rejection filtering, order outer operation lists to shrink before inner leaves, and decouple normally covarying valid parameters (`bytes: b"a"` vs. `declared_count: 2`) across all documented API preconditions regardless of current caller habits.

## 4. Referential transparency, CI build matrix, and Red–Green TDD

**Referential transparency; reified `FsMap` handlers; ambient-variable elimination.** Execution and shrinking require every trial to be a **referentially transparent** pure function `prop(input)` independent of trial order and parallel workers. Reify filesystem, archive, symlink, environment, or subprocess I/O into a pure transition `FsMap -> (Result, FsMap)` over a fresh per-trial temporary directory created *inside* the trial closure: materialize `(RelPath -> Entry)` under `root/d0/d1/work` alongside sibling entries (`root/a`, `root/d0/a` deeper than `".."` steps so parent-relative paths remain closed, total transitions checked via `snapshot_tree(root) == model_tree`), capture ambient globals (`$HOME`, `$TMPDIR`, `cwd`) via clean-environment child processes, and exercise root-relative `"/"` or mount-table logic only inside whatever isolated runner or container setup the host environment already provides.

**Standard CI build matrix; `Im(p) \ Pre(g)` caller checks; Red–Green regression completion.** Name tests, variables (`sut`, `model`, `ops`, `expected`), and assertion messages after the law (`parse_render_preserves_ast_spine`), keeping fixtures in `"a"`/`"b"`/`0..4` literals and redirecting verbose runner output to log files so you inspect compact `file:line` frames without copying raw tool banners. Run property suites and candidate patches across the ecosystem's **standard CI build matrix**—optimized release builds (`--release` / `-O2 -DNDEBUG`) alongside standard CI debug checks (`Miri`, `-race`, or `-O1 -g -fsanitize=address,undefined`)—so FFI bindings, new unit tests, and proposed fixes pass strict upstream CI cleanly without leaks, races, or release-mode divergences. When a property fails, follow ordinary **Red–Green test-driven bugfixing**: confirm `x in Pre(f)` under release builds—and if an internal helper `g` disagrees outside `Pre(g)`, test upstream `g(p(raw))` and record `Im(p) subseteq Pre(g)` as a verified invariant whenever the bad state is unreachable. Reduce confirmed counterexamples via **`ddmin`**, sweep sibling methods (`rg`) so related cases sharing one broken invariant group into one patch, and extract a dependency-free native regression test (`Red`) plus the smallest idiomatic fix (`Green`—or a passing characterization test when docs leave behavior open), noting plainly whether outer callers are `cited` or `unverified`.
