# Agents and property tests: refinement mappings and algebraic laws

Every optimized subsystem—an indexed store, an evicting cache, an incremental query planner, a streaming parser, a zero-copy archive, a safe FFI wrapper—is a concrete state machine `C` claiming a Hoare/Lamport **refinement mapping** `alpha: C -> A` (`alpha(step_C(c, op)) == step_A(alpha(c), op)` against a `BTreeMap`, fresh recomputation, or small-step interpreter) or a **forward simulation** relation paired with a representation invariant `RepInv(c)`. Distill that specification into small executable code and let `proptest` explore thousands of state transitions on the CPU until the diagram commutes or shrinks to a minimal counterexample.

Select and combine the generative lenses below as the module's structure warrants. When delegated a module brief inside a [`proptest-campaign`](../proptest-campaign/SKILL.md) worktree, work inside that worktree and return verified outcomes and cross-module leads to the coordinator.

## 1. Modeling and search direction

**Oracle independence; kernel inspection; white-box cutoffs (`Oracle from Contract ⊥ Generator from ker(alpha)`).** Derive the reference model `A` from public docs, call sites, and domain invariants using clean standalone types (`BTreeMap`, `Vec`, small interpreters) independent of `C`'s internal helpers. Then inspect `C`'s concrete fields, constants, and fast-path branches—noting every field on `C` erased by `alpha(c)`—to define `RepInv(c)` and aim generators directly at internal cutoffs: chunk/parallelism thresholds (`16_384` bytes), truncated hash fingerprints (`(h >> 32) as u32`), deferred eviction queues retaining deleted keys, cached derived strings, and multi-phase registration order. Keep compile-test-shrink loops in the `1–3s` range via leaf crates or narrow pocket test binaries.

**Myhill–Nerode distinguishability; mutation adequacy; unmasking layers.** Two histories `h1, h2` reaching equal abstract states `alpha(c1) == alpha(c2)` often leave distinct hidden residues in `C`—warmed caches, tombstones, freelist layouts, sharing topologies, unforced lazy fields—waiting for one distinguishing suffix `w` to separate them (`loom`/`shuttle` for thread-scheduler linearizability). Compare `Ok`/`Err` variant agreement and promised inner values directly: preserve order and counts for sequences, sort while preserving counts for multisets, and deduplicate strictly for sets. Calibrate an all-green suite via **mutation adequacy**: snapshot the target file's bytes, introduce a small invariant break, confirm the property catches it, and restore the saved bytes immediately. When a real failure fires, committing a validated fix onto the discovery branch and re-running routinely unmasks deeper divergences behind the first assertion.

**Existing-suite gaps; uncertainty markers; reactive point-fix neighborhoods.** Existing tests frequently restrict strings to narrow regexes (`"[a-z0-9_-]{1,12}"`—omitting quotes, `\\` / `\\"` runs, spaces, leading `-`, `\0`, and delimiters) or skip downstream consumers (`to_args() -> clap::try_parse_from()`). Grep for maintainer uncertainty markers (`TODO`, `FIXME`, `HACK`, `workaround`, `subtle`), and check `git log` for **reactive single-input point-fixes** (*"How Do Fixes Become Bugs?"*—hotfixes, release-blocker patches, urgent bounds-check commits) that update one half of a coupled invariant (changing growth from `*= 2` to `+ 128` while an adjacent reset still assumes `*= 2`) or guard one call site while sibling methods share the same assumption, alongside **recently added features/modes** meeting older caches, visitors, serializers, and GC passes.

## 2. Algebraic laws and specification repertoire

**Specification ladders; McKeeman differentials; Blum checkers and `EMI`.** Choose the strongest applicable rung on **Hughes's specification ladder** (`Refinement Mapping -> In-Repo McKeeman Differential -> Commuting Paths ("two ways to reach the same state") -> EMI / Metamorphic Rewrite -> Planted-Solution / Blum Checker -> RepInv Conservation`) rather than `is_ok()` smoke checks. Check whether the repo already holds a **McKeeman differential** pair (`SIMD vs. scalar fallback`, `incremental vs. cold batch`, `streaming vs. whole-slice`, `JIT vs. interpreter`, `Borrowed/Archived vs. Owned`). Where outputs are non-unique or expensive to compute, verify certificates in linear time (**Blum result checkers**: path validity, topological order + multiset conservation) or apply **equivalence-modulo-inputs (`EMI`) / metamorphic** rewrites (`e ~ e' => eval(e) == eval(e')`: reordering independent clauses, pruning dead branches, splitting chunks).

**Coupled views; recomputation naturality; relational and graph equivalence.** Step coupled representations (map + eviction queue, primary + secondary index, overlay + backing store, LRU + pool) alongside `A` across overwrites, removals, reinsertions, capacity cliffs, and empty/singleton states, checking `RepInv(c)` at every step. Assert `cached_query(c) == recompute_from_scratch(alpha(c))` across warmups, size-preserving edits, mode switches, and transitive invalidations; compare optimized graph/planner/AST passes against small interpreters over cycles, diamonds, shared DAGs, and deletion holes; and check scoping or visibility filters against flat `(actor, item, rule) -> bool` comprehensions.

**Monad-transformer ordering; external side effects; non-commutative monoids.** Distinguish atomic rollback (`StateT S (Except E): S -> Result<(A, S), E>`) from mutated error state (`ExceptT E (State S): S -> (Result<A, E>, S)`) and **external filesystem, cache, or symbol-table side effects persisting across `Err`**. Schedule deterministic `Err` returns on step `k` (exercising partial-init RAII `Drop`), drop manually polled `Future`s at arbitrary `Poll::Pending` suspension points, supply re-entrant trait/callback implementations (`Ord::cmp`, `Hash`, `Iterator`, `Drop`, `serde` visitors) that query or mutate `C` while `RepInv(c)` is open, and test layered config/option merges for associativity, `None` vs. `Some(empty)` identity, and `first-wins` vs. `last-wins` precedence across retried or rejected steps.

**Section–retractions; Rely–Guarantee pipelines; AST spine naturality.** Verify `parse(print(x)) == Ok(x)`, monoidal chunk homomorphism (`parse_chunks([a, b]) == parse_chunks([a ++ b])`), and cross-module **Rely–Guarantee** `produce -> consume` preconditions and input-output relations across `stringify -> reparse` boundaries. Where two passes scan one input (pre-splitter then slice parser, or right-to-left vs. left-to-right), verify quote/escape parity (`\\"`). Where builders substitute strings into AST data leaves (URLs, globs, filters, queries, CLI args), verify **AST spine invariance**: varying leaf characters must either return `Err` or change leaf values alone in `parse(render(ast))`, leaving outer AST constructors, operator counts, and authority fields invariant.

**Quotient congruence; Galois span pushforwards; `M_scan == M_apply` and IEEE-754 cliffs.** Verify congruence (`a == b => hash(a) == hash(b)`, `cmp(a, b) == Equal`, `norm(norm(x)) == norm(x)`, and `obs(a) == obs(b)` on representation-insensitive observations across `0!` epochs, `.0` suffixes, and `Archived<T>` vs. owned `T`). Compare dry-run / `list_entries` / size-calculation passes against execution (`M_scan == M_apply`), validators vs. evaluators reading distinct projections (keys vs. values, first vs. last duplicate key, empty-body defaults `"" -> "{}"`), budget trackers across multi-chunk/`Err` paths, IEEE-754 cliffs (`2^53`, `-0.0`/`+0.0`, `NaN`, stateful Kahan retry compensation), and byte-span pushforwards across length-changing UTF-8 or normalization maps.

## 3. High-density generators and shrinking

**Small-scope hypothesis; free-monoid alphabets; planted and decoupled inhabitants.** Apply **Jackson's small-scope hypothesis**: pair explicit `Op` enums with tiny capacities (`0..7`), chunk sizes (`1..5`), `0..4` key pools, and threshold neighborhoods (`T - 2..=T + 2`), building string/path/URI/glob/CLI inputs combinatorially from `"a"`, `"b"` crossed with the grammar's own delimiters over lengths `0..8` so counterexamples shrink to 2–5 character literals (`"/@a:a"`, `"\\[*]"`). For constraint or resolution domains, plant a valid witness *first* and construct the problem around it to test feasibility via a Blum checker (applying objective bounds only where optimality is promised, and exact equality only where solutions are unique). Generate `x ~ y` pairs via equivalence-preserving rewrites, and vary normally covarying safe parameters (`bytes: b"a"` vs. `declared_count: 2`) independently across all safe inhabitants.

**Groce swarm subsets; index-preserving shrinking; caller-habit independence.** Embed history motifs (`warm -> mutate -> read`, `remove -> reinsert`, `populate -> clear -> repopulate`, `snapshot -> mutate -> read_both`) and mix **Groce swarm-subset traces** (`3–5` `Op` variants and feature flags per trace so `Clear` and eager `Get` do not suppress `Resize` or cold `Snapshot`s) with full-vocabulary traces. Prefer `proptest::sample::Index` over heavy `prop_assume!` or deep `prop_flat_map` chains (keying custom procedural PRNG draws by `(label, occurrence)` and shrinking containers before leaves), and vary everything permitted by documented API/`unsafe` preconditions regardless of current caller habits.

## 4. Hermetic execution, sanitizers, and fix extraction

**Reynolds frame confinement; safe-wrapper soundness; `--release` parity.** Format `prop_assert_eq!` failures as equation diffs (`step {k} ({op:?}): alpha(impl) = {actual:?}, model = {expected:?}`). Enforce **Reynolds frame laws** (`modifies(work) * UNCHANGED(outside)`) on path, archive, symlink, config, and cleanup suites via per-case `TempDir`, spawning a child `Command` per case when code reads `$HOME`, `$TMPDIR`, or `cwd` from process globals; when generated paths (`"/"`, `".."`, symlinks) reach mutating filesystem calls, wrap execution in read-only bind-mount / namespace confinement (`bwrap --ro-bind / / --bind "$temp" "$temp"`, Landlock, or an isolated container) with nested writable ancestor sentinels (`temp/d1/d2/work` beside `temp/a`, `temp/d1/a`, `temp/d1/d2/a`) so even error-swallowing cleanup calls hit an observable sentinel inside `snapshot_tree(temp)`. Check `unsafe`/`Pin`/arenas under `Miri` (`PROPTEST_DISABLE_FAILURE_PERSISTENCE=1 PROPTEST_CASES=16 cargo +nightly miri test`), C/FFI wrappers under `ASan`/`UBSan` at `0–2` byte sizes, and every candidate divergence under `--release` (`-DNDEBUG`).

**State-equation diagnosis; delta debugging; ownership-calibrated extraction.** When a run surfaces a failing seed or sanitizer backtrace, read it directly as a state-transition equation: locate the first diverging step `k`, isolate minimal conditions via **delta-debugging (`ddmin`)**, sweep sibling methods (`rg`), and quotient traces sharing one broken invariant into a single **root-cause equivalence class**. Write a clean standalone `#[test]` from scratch at the established contract boundary and verify it in a fresh context against target docs and `--release` / sanitizer gates—confirming pre-fix failure and post-fix pass for settled bugs, or capturing a passing characterization test with competing options when docs are silent, while stating accurately whether outer callers are cited or `unverified`. Route external fixes as minimal surgical branches, owned-codebase veins via [`root-and-branch`](../root-and-branch/SKILL.md), and tradeoff or maintainer-channel notes via [`write-reports`](../write-reports/SKILL.md).
