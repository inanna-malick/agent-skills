# Python property-testing harness (`Hypothesis`)

Apply these Python-specific patterns alongside the specification, generator, and effect-reification principles in [`SKILL.md`](../SKILL.md).

**Fast leaf loops (`0.5–2s`).** Invoke `pytest path/to/test_law.py -k <law_name> -q` directly (with `--no-cov` when repo `pyproject.toml` enables coverage plugins by default) so compile-free iteration stays sub-second. Decorate discovery properties with `@settings(max_examples=300, deadline=None, database=None, print_blob=False)` while iterating, widening `max_examples=1000..2500` once initial laws hold, and redirect verbose runner traces to `/tmp/hypothesis.log` so you inspect compact `file:line` frames and minimal falsifying examples.

**Stateful machines and index-driven selection.** For stateful containers, caches, planners, or incremental stores, subclass `hypothesis.stateful.RuleBasedStateMachine`: store the brute-force reference state `self.model` (`dict`, `list`, `set`, exact `int` or `fractions.Fraction`) alongside `self.sut`, emit handles into `Bundle`s, check `RepInv` and `alpha(self.sut) == self.model` inside `@invariant()`, and mix Groce swarm feature/rule masks via `@initialize()` flags. Prefer `st.sampled_from(...)` and `st.data()` index draws (`data.draw(st.integers(0, len(live) - 1))`) over `assume(...)` so shrinking does not stall on filter rejections. Build string/URI/glob/query inputs from `st.lists(st.sampled_from(["a", "b", *delimiters]), max_size=8).map("".join)`.

**Per-trial `FsMap` purity (avoiding `pytest` fixture aliasing).** Never pass `pytest`'s function-scoped `tmp_path` or `monkeypatch` fixtures directly into an `@given` function—`pytest` constructs function fixtures *once* across all generated examples, causing trials to mutate shared filesystem or environment state and breaking shrinking determinism. Instead, enter `with tempfile.TemporaryDirectory() as root:` *inside* each `@given` call (or inside `RuleBasedStateMachine.__init__` / `teardown`), materialize `root/d0/d1/work` plus sibling entries (`root/a`, `root/d0/a`), compare `snapshot_tree(root) == model_tree` as pure dictionaries, and run subprocesses via `subprocess.run(..., cwd=work, env=clean_env, check=False)`.

**Dynamic-type, numeric, and C-extension boundaries.**
- **Exact `int` vs. fixed-width/float cliffs:** Python `int` is unbounded `Z`, whereas NumPy/Arrow buffers, `struct.pack`, SQLite, and C/Rust extensions (`ctypes`, `cffi`, `PyO3`, Cython) truncate or wrap in `Z_2^64` / `Z_2^32`; probe `2**31 - 1..2**31 + 1`, `2**53` (`float` precision cliff), `2**63 - 1..2**63 + 1`, `-0.0`, `math.nan`, and `Decimal` vs. `float` roundtrips.
- **Mutability aliasing and truthiness:** Test `bool(x)` bugs where valid zero/empty values (`0`, `0.0`, `""`, `[]`) hit `if val:` instead of `if val is not None:`, default-argument or cached-dict aliasing across calls, and generator/async-coroutine cancellation (`aclose()` / early `break` leaving `RepInv` open).

**Clean `pytest` / `unittest` extraction.** Once Hypothesis shrinks to the minimal falsifying sequence, translate it into a standalone, dependency-free `def test_<component>_<invariant>():` (or `unittest.TestCase` method) using plain literals and `assert actual == expected`, leaving zero `@given` scaffolding in repositories that do not already use Hypothesis.
