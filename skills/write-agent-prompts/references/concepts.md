# Conceptual grounding

The skill applies these referents to prompt construction. The sources establish the underlying concepts; their use here is a design synthesis. Human cognition research does not establish that an LLM implements the same mechanism, and a named concept does not guarantee a behavioral effect.

| Referent family | Contribution to prompt construction | Source |
| --- | --- | --- |
| Common ground and grounding in communication | Exploit shared knowledge while making task-specific meaning sufficiently clear for the purpose. | [Clark and Brennan, Grounding in Communication](https://www.cs.cmu.edu/~illah/CLASSDOCS/Clark91.pdf) |
| Cognitive task analysis and the critical decision method | Recover cues, expectations, interpretations, and judgments from concrete examples of expert work. | [Klein, Critical Decision Method](https://www.gary-klein.com/cdm); [The Value Added by Cognitive Task Analysis](https://journals.sagepub.com/doi/abs/10.1177/154193129503900920) |
| Recognition-primed decision making | Connect situation recognition to plausible actions and expectations that can be checked. | [Klein, Recognition-Primed Decision Model](https://www.gary-klein.com/rpd) |
| Problem representation and representational change | Consider which representation makes useful operations and relationships accessible. | [Fink, Automatic Representation Changes in Problem Solving](https://www.cs.cmu.edu/~eugene/research/abstract/phd-thesis.html) |
| Data-frame sensemaking | A frame directs attention and the search for evidence; evidence can also require revision of the frame. | [Klein, Data-Frame Theory](https://www.gary-klein.com/data-frame) |
| Structural alignment, systematicity, and analogical transfer | Transfer connected relational structure and recognize the limits of the correspondence. | [Northwestern Qualitative Reasoning Group, Structure-Mapping](https://www.qrg.northwestern.edu/ideas/smeidea.htm) |
| Rational metareasoning and value of computation | Judge additional reasoning by its expected contribution to consequential choices. | [Russell, Bounded Optimality and Rational Metareasoning](https://people.eecs.berkeley.edu/~russell/research-bo.html) |
| Partial evaluation and specialization | As an analogy: specialize a general writing method using the known task and recipient, preserving the choices that depend on later context. | [Jones, Gomard, and Sestoft, Partial Evaluation](https://studwww.itu.dk/people/sestoft/pebook/) |
| Cognitive apprenticeship: modeling | Make the technique visible in its application. Here the relevant part is demonstration; the recipient remains a capable peer. | [Collins, Brown, and Holum, Cognitive Apprenticeship](https://www.aft.org/index.php/ae/winter1991/collins_brown_holum) |
| Construct validity | Check that evaluation measures the intended capability. For this skill, evaluate guidance through the decisions and artifacts it enables. | [Cronbach and Meehl, Construct Validity in Psychological Tests](https://conservancy.umn.edu/bitstream/11299/184279/1/1_07_Cronbach.pdf) |

The conceptual repertoire is open. Use these connections to recruit other relevant methods, representations, and lenses. A cue can justify inclusion by making a useful possibility salient before a particular target or action has been selected.
